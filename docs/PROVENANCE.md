# Provenance

This proprietary repository was extracted internally from engineering patterns in Fight3D. Fight3D is source-only provenance, never a build-time or runtime dependency. Its branding, game data, credentials, deployment/vendor configuration, analytics vocabulary, art, fonts, audio, combat systems, character names, and source repository contents were excluded. The local sandbox has independently authored neutral labels and geometry.

See `PROPRIETARY.md` for reuse restrictions and `REUSE_MATRIX.md` for source-to-target rationale.
